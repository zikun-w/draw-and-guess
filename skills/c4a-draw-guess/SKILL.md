# 陪群友玩你画我猜

用自己的昵称和一个独立座位参加。工具需要 Python 3.7+ 和能访问游戏站点的网络。猜图时，把下载的 PNG 交给当前 Agent 的看图工具或支持图片的模型。所有命令在本技能目录下执行。同机多位 Agent 各自设置不同的 `DRAW_PROFILE`，同一位玩家按顺序执行命令。部署在其他站点时设置 `DRAW_SITE`。

以昵称「澜」为例，先设置 `export DRAW_PROFILE=lan`，然后根据这次邀请入座。

- 对方现在约你一起玩，没给房间，就执行 `python3 scripts/play.py create 澜`。入座成功后把实际输出的邀请链接发回当前聊天。
- 邀请中有本站链接或房间号，就执行 `python3 scripts/play.py join 澜 '本次邀请链接或房间号'`。如果对方特指某个已有的房间，却忘了给房号，向对方要链接。
- 在同一聊天重复邀请同一局，先用 `python3 scripts/play.py state` 核对之前的房间。对方聊上局、问玩法或转述别人的邀请时，按聊天内容回答。

约好的人到齐且你是房主时执行 `start`。每条命令的结果都有 `next`，读它来决定下一步。

| next | 怎么玩 |
| --- | --- |
| `wait` | 留在房里，过几秒执行 `state`。 |
| `start` | 房主已经可以开局，先看在线名单。 |
| `choose` | 看 `choices`，用 `choose 0` 选第一个词，依此类推。选词窗口只有 12 秒。 |
| `draw` | 只看自己收到的 `word`，画出最能让人认出来的轮廓。可以分批补细节。 |
| `guess` | 新笔迹出现时执行 `board /tmp/guess-lan.png`，看图，结合 `wordLength`，用 `guess 雨伞` 这样的命令答一次。用自己的 `guessed` 和得分确认。 |
| `finished` | 看得分，与群友聊聊这局。收到再开一局的邀请可以 `start`，退出用 `leave`。 |

**画笔示例**　画布左上角是 `[0,0]`，右下角是 `[1000,650]`。矩形和椭圆给两个对角，一条折线按落笔顺序给点。`sketch` 按数组顺序逐段落笔，网页和 PNG 都能看到中途的画面。下面两笔先画钟面，再画指针。

```sh
python3 scripts/play.py sketch '[{"kind":"ellipse","points":[[330,150],[650,470]]},{"kind":"line","points":[[490,190],[490,310],[580,350]],"color":"#df594a","width":9}]'
```

用 `undo` 撤销一笔，`clear` 清空自己的当轮画板。每次提交都使用上次看到的回合和画板版本。遇到 409 先读 `state`，确认是否已经画上或轮到别人了。发言间隔、同一出口 IP 的多人轮询都可能触发限速，稍等再读状态。正常游戏隔几秒看一次，笔迹序号 `seq` 有变化再取图。连续约 45 秒没有请求会掉线；原座位仍保留时，用同一 profile 和原房间号重新 `join`。

如果站点提示接口不存在，向邀请人说明站点需要更新。只有文字和图片收发能力的 C4A Agent 可以请群友发画板截图参与猜图；独立入座需要宿主能执行这个脚本或调用同样的 HTTP 接口。
